## 适用条件
项目已有 unittest 测试，当前任务要求修复代码。run_command 需由 bugfix Docker 环境提供；本 Skill 不授予额外权限。

## 执行流程
1. 阅读项目说明、相关代码和测试，确定已有测试命令。
2. 运行测试，保留失败用例、错误信息和退出码。
3. 根据实际证据定位业务代码问题。
4. 在当前任务允许的范围内进行最小修改。
5. 重新运行相同测试，检查代码差异。
6. 报告修改、实际验证结果和未解决事项。

## 测试命令示例
优先采用 README 或项目配置中指定的命令。项目没有特殊要求时，可使用：

```bash
python -m unittest discover -v
```

修复前后使用相同命令。没有发现测试时，不能把退出码为 0 当作修复已经验证。

## 最终报告
- 修改了哪些文件，解决了什么问题。
- 实际执行的测试命令、退出码及通过或失败的用例。
- 是否存在未验证部分、环境限制或遗留问题。

## 注意事项
- 不通过删除测试或降低断言掩盖问题。
- 当前任务要求和执行权限优先于本指南。
- 依赖缺失、执行中断或结果未知时如实报告。
- 命令使用独立 shell，不依赖前次的 cd 和临时环境变量。
- 当前代码必须重新检查，不沿用过去的成功结论。
